# Running Sum

This program reads a list of integers and prints the running sum after each value.

A running sum is the total of all values from the beginning of the list up to the current position.

## Input

1. Enter the number of values, `n`.
2. Enter the `n` integers. Enter one integer per line.

Example input:

```text
4
1
2
3
4
```

## Output

The program prints each cumulative total on one line:

```text
Running sum: 1 3 6 10
```

The totals are calculated like this:

- First total: `1`
- Next total: `1 + 2 = 3`
- Next total: `1 + 2 + 3 = 6`
- Final total: `1 + 2 + 3 + 4 = 10`
