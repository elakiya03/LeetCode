# Longest Streak

This program finds the length of the longest consecutive streak of the same number in an array.

## Problem

Given an array of integers, find how many times the same number appears in a row before it changes.

Example array:

```text
1 1 1 2 2 2 2 3 3
```

Here, the longest streak is:

```text
4
```

because `2` appears 4 times in a row.

## Input

The program asks for:

1. the number of elements `n`
2. `n` integer values

Example input:

```text
9
1 1 1 2 2 2 2 3 3
```

Or in the program's interactive form:

```text
Enter no of elements: 9
Enter 9 values
1 1 1 2 2 2 2 3 3
```

## Output

The program prints the length of the longest consecutive streak.

Example output:

```text
Longest streak: 4
```
