# Program: Palindrome Checker

`Description`: Reads a string and checks whether it is a palindrome.

1. Two Pointer — Time: O(n), Space: O(1)
2. Single Pointer — Time: O(n), Space: O(1)
3. Recursion — Time: O(n), Space: O(n) due to the call stack
4. Reverse string and compare — Time: O(n), Space: O(n) for the reversed copy
